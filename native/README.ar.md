# native/

[English](README.md) | العربية

المصادر الأولية والحزم العامة المُصانة جنبًا إلى جنب مع DeepSeek Harness. مساحة العمل [`system/`](system/README.ar.md) هي المسؤولة عن مشغّل Landlock، وربط POSIX flock، وحزم المنصات، و[عملية الإصدار](system/docs/release.md).

**مساحة العمل وحُدود الإصدار**

تنتمي `system/` وحزمُها إلى مساحة عمل pnpm للحقيبة الجذرية للمستودع، وتتشارك معها ملف القفل الرئيسي. تستخدم الجهات المستهلكة لـ harness أثناء التطوير والتكامل المستمر (CI) حزم المدخلات المباشرة لمساحة العمل الحالية؛ لذا فإن التغييرات في اتفاقيات المشغّل وتحديثات الجهات المستهلكة يمكن تنفيذها واختبارها معًا ضمن تعديل واحد.

يقوم سير العمل `Node Addon System` في المستودع الرئيسي ببناء واختبار كل بنية معمارية مدعومة. بينما يجمع `Node Addon System Release` هذه المخرجات الأولية، ويقوم بحزم وتأكيد حزم npm (tarballs)، ثم يُتيح خيار نشرها بنفس إصدار الحزمة الأولية. تستمر حزمة المدخلات في الإعلان عن حزم المنصات كاعتماديات اختيارية (optional dependencies) في npm، مما يضمن أن npm لن يثبّت سوى الحزمة المتوافقة مع نظام تشغيل المستخدم ومعالجه (CPU).
